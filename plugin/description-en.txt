LibreOffice MCP Server Extension

This extension is a LibreOffice-native HTTP tool bridge designed for MCP integration, enabling AI assistants to interact with LibreOffice documents in real-time. It exposes a custom REST API rather than native MCP JSON-RPC; using it from an MCP client currently requires an MCP-to-REST adapter.

Key Features:
- Direct document manipulation via UNO API
- Real-time text insertion and editing
- General document lifecycle support (create/open/save/export) across Writer, Calc, Impress, and Draw, plus a Writer-focused live editing surface
- Live document analysis
- HTTP API for external AI assistant connections, trusted-localhost-only with no authentication

Installation:
1. Download the extension (.oxt file)
2. Open LibreOffice
3. Go to Tools > Extension Manager
4. Click "Add" and select the .oxt file
5. Restart LibreOffice

Usage:
After installation, start the server manually from Tools > MCP Server > Start MCP Server. Once started, it is accessible via HTTP on localhost:8765. Configure your AI assistant to connect to this endpoint for LibreOffice document operations.
